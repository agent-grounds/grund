- [§FS-fmt.2.4](../../functional-spec/FS-fmt.md#24-shorthand-to-canonical), [§FS-fmt.2.4.6](../../functional-spec/FS-fmt.md#246-an-absent-target-section-withholds-this-rewrite-and-only-this-one), [§FS-check.3.24.1](../../functional-spec/FS-check.md#3241-the-release-attribution-and-where-the-command-clause-is-withheld), [§DF-declaration-local-section-shorthand.2.5](../../decisions/functional/DF-declaration-local-section-shorthand.md#25-stored-citations-carry-their-full-id): `grund fmt` no longer expands a declaration-local section citation onto a section its owner does not have. A bare `<§>12` in a declaration whose sections stop at `2.1` was rewritten to the full `<§>FS-a.12` and left `grund check` reporting the same `missing section` error at the same line, now against a canonical-looking citation of a section that is not there — and the cross-document target the author meant was no longer recoverable from the text. The precondition for that rewrite gains a resolving target: an owner with no heading at the cited numeric path leaves the token byte-identical in dry-run and write mode alike, over all three shapes a path can fail at (wholly absent, partially resolving, and an owner with no numbered sections), while a resolving site expands exactly as before. The finding at a refused site drops its `` ; run `grund fmt --write` `` clause and nothing takes its place, because a finding never names a command that would answer `rewrote 0 lines` ([§FS-check.3.17.5](../../functional-spec/FS-check.md#3175-anything-else-is-not-an-entry)); its code, severity, and the `missing section` error beside it are unchanged, so the shipped text stays a verbatim prefix ([§FS-check.3.24.2](../../functional-spec/FS-check.md#3242-an-append-not-a-wording-change)). Number-only ID shorthand is deliberately untouched: it already names its declaration, while the declaration-local rewrite is the one that picks an owner from the site's position. A tree an earlier run already rewrote is not repaired; this stops the damage. Closes [issue #378](https://github.com/agent-grounds/grund/issues/378). (PR #380)
