- `clean.sh` at the repository root gives back the disk a checkout's builds took: it runs `cargo clean`, then removes every directory holding a valid `CACHEDIR.TAG`, such as a plan's scratch build under `panta/`. It is the clean verb `ephor clean` runs at the root of a branch checkout no live run holds, and it exits 0 when done. Closes [issue #397](https://github.com/agent-grounds/grund/issues/397).
