- [§FS-rules.9.1.1](../../functional-spec/FS-rules.md#911-a-path-scoped-check-compares-against-the-same-render): in a repository with a `rules = true` kind, a path-scoped `grund check` compares the managed block's `### Chapter rules` against the same render `grund check .` does, so neither run calls the block `init` wrote stale and both call a block missing a bullet stale. This has held since v0.15.0, which made a path scope narrow the report and not the resolution ([§FS-check.1.3.6.1](../../functional-spec/FS-check.md#1361-a-path-scope-narrows-the-report-not-the-resolution)); it is now specified and pinned by a test. Closes [issue #377](https://github.com/agent-grounds/grund/issues/377). (PR #387)
