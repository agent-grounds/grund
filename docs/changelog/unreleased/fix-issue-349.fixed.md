- [§AR-ci.3.3](../../architecture/AR-ci.md#33-test-only-observers): a plain `cargo test --workspace --all-targets --locked` is green on a clean tree. Three `show --batch` tests count workspace loads through an observer only the `test-workspace-load-count` feature compiles in, and without the feature the count read an unwritten log as zero, so one test failed naming a file, a line and two integers and two passed having observed nothing. A build without the feature now reports those tests `ignored`, naming `grund/test-workspace-load-count`, while the exit, stdout and stderr assertions of the same cases still run in every build. [§AR-ci.3](../../architecture/AR-ci.md#3-current-hooks) now spells the command the gate runs, feature included, and a test holds it to the `cargo-test` hook. Closes [issue #349](https://github.com/agent-grounds/grund/issues/349). (PR #394)
