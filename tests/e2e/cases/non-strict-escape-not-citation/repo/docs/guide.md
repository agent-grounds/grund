# Guide

Login is specified in FS-login, an ordinary bare citation because this
repository runs in compatibility mode. The member rule is §api/FS-x.

The shape of a citation is written <§>FS-user-login in prose, and
`<§>FS-user-login.3.1` inside an inline-code span. Across a namespace the same
illustration reads <§>api/FS-x.
