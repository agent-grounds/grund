# Requirements

## FS-session: Sessions end when idle or too old

A session ends after a stretch without a request, and after a fixed
lifetime however busy it is. Both limits are values, an amount and its
unit, so a document can quote either one whole.

### 1. Idle timeout <!-- grund:value -->

#### 1.1. 45

#### 1.2. minutes

### 2. Absolute lifetime <!-- grund:value -->

#### 2.1. 720

#### 2.2. minutes
