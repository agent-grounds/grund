- [§FS-rules.5.1.1](../../functional-spec/FS-rules.md#511-a-chapters-display-name-is-the-label-its-author-wrote), [§FS-rules.3.1](../../functional-spec/FS-rules.md#31-chapter-presence): a chapter rule now counts a chapter declared in a source doc-comment. A heading such as `/// ## terms: Terms` was recorded with the whole comment line as its display name, so `Each AR must have exactly one Terms chapter.` reported `AR-inline has 0 Terms chapters` for a chapter `grund AR-inline.terms` printed, and `grund list --selector AR.terms` titled the row `/// ## terms: Terms`; no chapter rule could reach any source declaration. The comment around the heading — `///`, `//!`, a block comment's ` * `, `#`, `--`, `;` — is no longer part of the label, so the chapter is the same fact as the same heading in Markdown and the selector row is titled `Terms`. Markdown section titles, and the anchors derived from them, are unchanged. Closes [issue #351](https://github.com/agent-grounds/grund/issues/351). (PR #TBD)
