- [§FS-config.3.1.8](../../functional-spec/FS-config.md#318-inline_style-and-the-note-budgets): an invalid `[reference] inline_style` value is now rejected by a message that names the value and the accepted set, ``unknown [reference] inline_style `note` (expected citation-with-note or citation-only)``, the form its sibling `[reference]` enums already use. It used to stop at `unknown [reference] inline_style`, which read as a complaint about a key that exists and is spelled correctly, and never said what to write instead. The earlier text survives as the message's prefix, and the exit codes of `grund check` (`2`) and `grund config validate` (`1`) are unchanged. Closes [issue #284](https://github.com/agent-grounds/grund/issues/284). (PR #396)
