- [§AR-ci.10.3](../../architecture/AR-ci.md#103-a-fixture-root-inherits-no-config-from-above-it): `grund-core`'s unit suite no longer passes or fails according to where `TMPDIR` points. Its fixture helper built every root under the system temp directory, and discovery climbs from there to the filesystem root ([§FS-config.1](../../functional-spec/FS-config.md#1-file-location-and-discovery)), so a `grund.toml` or `.agents/grund.toml` above `TMPDIR` became the config of the suite's zero-config cases and failed two of them as though discovery had regressed. The helper now takes the first temp base no config covers, the system temp directory and then `/tmp`, and when every one is covered it fails naming `TMPDIR`, each candidate and the config covering it; the zero-config case names the absolute path of any config it finds. Discovery itself is unchanged. Closes [issue #280](https://github.com/agent-grounds/grund/issues/280).
