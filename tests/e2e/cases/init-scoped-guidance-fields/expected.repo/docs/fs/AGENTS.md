## Grounding with grund (block v45)

These rules cover the files under `docs/fs/`; the rest of this project's grund guidance is in the root `AGENTS.md`.

### Citation directions

`must`/`never` are `grund check` errors; `should`/`avoid` are suggestions (`grund check --suggestions`).

- Each **FS** declaration must cite GOAL.
Anything not listed above is allowed.

### Declaration shapes

- **FS**
