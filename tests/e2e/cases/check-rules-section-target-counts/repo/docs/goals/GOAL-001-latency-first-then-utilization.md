# GOAL-001-latency-first-then-utilization: Latency first, then utilization

Serve each arrival quickly before packing the fleet tightly.

## 1. Latency

Tail latency is held under its budget.

## 2. Utilization

Spare capacity is reclaimed only once latency holds.

## 3. Trade-off

Latency wins every tie.

## 4. Outcome

The arrival model predicts tail latency within five percent.

## evidence: Evidence

A benchmark that validates the model is the evidence for this goal.
